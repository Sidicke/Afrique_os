# Décisions ouvertes — ne pas inventer de règles

| Sujet | Proposition par défaut | Validation requise |
|---|---|---|
| Missions publiques agences | Agences peuvent recevoir des offres selon règles explicites ; ne pas activer sans choix | Oui |
| Livreurs d'agence | Missions de leur agence exclusivement | Validé |
| Livreurs indépendants | Missions publiques éligibles | Validé |
| Livreur personnel vendeur | Possible ; paiement plateforme ou externe clairement indiqué | À préciser |
| Gare | Client choisit parmi gares desservies, suggestion par défaut | Validé |
| Chauffeur occasionnel | Aucun compte obligatoire ; reçu et preuve de transfert | Validé en principe |
| Retrait gare | Confirmation client via compte ou lien sécurisé ; pas de 24 h sans preuve | À valider |
| Délai de conformité | 24 h après livraison vérifiée, sans litige, sous réserve du droit applicable | À valider juridiquement |
| Preuve remise locale | Code client à usage unique + contrôles et recours | À valider |
| Frais de livraison | Grille par zones + contrats partenaires + exceptions | Validé en principe |
| Paiement agence | Crédit agence, pas employé | Validé |
| Transporteur interurbain | Responsabilité, assurance, perte, SLA, reçus | À négocier |
| Séquestre | PSP agréé offrant retenue/split/payout compatibles | Bloquant avant production |
| Wallet | Ledger interne, pas conservation autonome de fonds | À confirmer par audit |
| Chat | Fermé à livraison vérifiée ; réouvert pour nouvelle mission même couple | Validé |
| Commande multi-vendeur | Adapter au checkout réel ; expéditions distinctes si besoin | Audit |
| Client invité | Lien sécurisé pour suivi et réception | À valider |
| Prix exacts | 1 000/1 500 FCFA ne sont que règles d'exemple | À fixer |

**Priorité :** résoudre les points bloquants avant paiement réel ; les autres peuvent être paramétrés pour un pilote limité.
